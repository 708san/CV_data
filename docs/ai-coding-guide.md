# AIに改造を相談するガイド

AIに最初に渡すプロジェクト仕様は[AI向けプロジェクト実装コンテキスト](ai-project-context.md)にまとめています。高校生向けのデータ・処理選びは[生徒向け索引](student-data-index.md)、APIの正確な仕様は[APIリファレンス](api-reference.md)が基準です。

ChatGPT、CodexなどのAIに相談するときは、「何を作るか」だけでなく、使うデータ、実行場所、見たい結果、守る条件も伝えます。題材や見せ方を自分の困りごとに合わせて変えてください。

メソッドの正確な名前、引数、既定値、戻り値は[公開APIリファレンス](https://github.com/708san/CV_data/blob/main/docs/api-reference.md)が基準です。AIにコードを作らせる場合は、そのページと使用データの説明を読ませます。AIがリポジトリを参照できない場合は、該当箇所を依頼文に添付してください。列名や関数名を推測で作らせないようにします。授業での実行例はGoogle Colabを標準にし、公開PyPI版を使います。

## 依頼に入れる情報

1. **目的**：誰が、どんな場面で、何に困っているか。
2. **データ**：使うデータID、または自分の画像。ラベルや列の意味。
3. **処理**：分類、回帰、OCR、検出、領域分割、画像生成のどれを試すか。
4. **入力と出力**：何をモデルへ渡し、画面や表に何を表示したいか。
5. **環境**：Google Colabかローカルか、CPUかGPUか。
6. **成功の確かめ方**：どんな例を確認し、何と比べるか。
7. **変更の範囲**：変えてよいコードや設定、維持したい部分。

## そのまま使える依頼ひな形

`< >`の部分を自分の課題に合わせて書き換えてください。

> Google ColabのPython 3.11〜3.13で実行するコードを作ってください。目的は「<誰のどんな困りごとを、どう助けたいか>」です。入力には<cvlessonのデータID / 自分の画像>を使います。CV教材ライブラリのAPIリファレンス（https://github.com/708san/CV_data/blob/main/docs/api-reference.md）と該当データ説明を確認し、そこに書かれた関数名・引数・列名・戻り値だけを使ってください。不明な場合は、先にカタログや`data.to_df().columns`を確認する短いセルを作ってください。方法は<分類 / 回帰 / OCR / 検出 / 領域分割 / 画像生成 / まだ決めていない>です。結果は<画像への枠・マスク / 読み取った文字 / 予測ラベルや数値 / 生成画像など>で見たいです。成功は「<どの例を確認できればよいか>」で確かめます。まず基本の短いコードを示し、変更点を少しずつ説明してください。既存パッケージの削除や無関係な依存の更新はせず、追加インストールが必要なら機能別コマンドと新しいColabランタイムを案内してください。データやモデルの利用条件、出典、元画像、個人情報を勝手に変更・公開・外部送信しないでください。GPUが必要なら、利用可能か確認してから明示してください。最後に、結果の限界と人が確認すべき点も説明してください。

## AIに既存の使い方を確認してもらう

データのIDや列名を想像で決めず、カタログと実データを調べるコードから始めます。

```python
from cvlesson import datasets

print(datasets.list_tasks(audience="student"))
print(datasets.list_available(audience="student"))
print(datasets.info("使いたいデータID"))
```

取得した後、表の列・分割・画像例を確認します。

```python
data = datasets.get("使いたいデータID")
frame = data.to_df()
print(frame.columns.tolist())
print(frame.head())
data.show_examples(6)
```

基本インストールで`to_df()`と画像サンプル表示が使えます。ResNet分類・回帰、検出・領域分割、画像生成は機能別extraで必要なPython依存を追加します。データとモデルの接続は[対応表](data-model-compatibility.md)を確認してください。

## 機能を選ぶ目安

- 画像に決められた種類のラベルを付ける：`ResNetClassifier`
- 画像または画像ペアから数値を予測する：`ResNetRegressor`
- 画像に写った文字を読む：`ocr.load()`（学習済みモデルの推論）
- 既定カテゴリの物体と位置を探す：`vision.load_detector()`
- 点や枠で選んだ対象のマスクを作る：`vision.load_segmenter()`
- 新しい画像や絵柄を作る：`generation.load()`（SDXLとLoRA）

この一覧は選択肢です。目的に合わない場合は、データ説明とモデルの限界を見て別の方法に変えてください。検出・領域分割・OCRの追加学習、LoRA学習、ResNet本体の全層微調整は、このライブラリの機能ではありません。

## AIが作ったコードを確かめる

- コードが実際のデータID、列名、タスク、返り値を使っているか確認する。
- 利用するデータ・LoRAのライセンス、出典、商用可否など個別条件を読む。パッケージコードのMITはデータやモデルに適用されません。
- `fit()`は学習用データに、`score()`は分けておいた検証用またはテスト用データに使う。
- メソッドの引数・戻り値・対応するタスクは[APIリファレンス](api-reference.md)で実装と照合する。存在しない引数、データにない列、未対応の学習機能を補って書かない。
- OCRの読み取り文字は`result.to_dict()`で保持・受け渡しできます。Notebookでは`display.show_ocr(image, result)`で一覧と行別画像を確認し、元画像と照合します。検出の枠、SAMのマスク、生成画像も元画像と比べ、モデルのスコアだけで正しさを決めない。
- 画像、マスク、モデル重みをGitやPyPIへ追加しない。自分の画像に個人情報や他人の顔がある場合は共有範囲を確認する。
- エラーが出たら全文、実行環境、直前に実行したセル、使ったデータIDをAIに伝える。既存環境からパッケージを無計画に削除させず、まず原因と安全な修正案を求める。

AIは間違ったコードや説明を出すことがあります。実行結果・利用条件・課題に合うかを自分で確かめてください。
