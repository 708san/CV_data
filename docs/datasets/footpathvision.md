# FootpathVision（条件付き候補・公開保留）

- **公式版**：[Mendeley Data Version 1](https://data.mendeley.com/datasets/szkhrh8dc8/1)（DOI: 10.17632/szkhrh8dc8.1）
- **表示ライセンス**：CC BY 4.0（公式ページ表示。元動画ごとの権利は未審査）
- **状態**：一次情報の机上確認のみ。画像・ファイルは取得していません。

## データの内容

公式ページは、ダッカ市で撮影された歩道画像1,238枚を説明しています。屋台、手押し車、家具、違法駐車などによる「通行を妨げられた歩道」と「妨げのない歩道」の2分類です。作者が撮影した画像と、Creative Commonsライセンス付きYouTube動画から切り出したフレームを別フォルダで提供するとされています。表示される2つのZIPは2.41GBと1.9GBです。

## 高校生の課題との接続

徒歩や車いすで通りやすい道を考えるアクセシビリティ課題に使える可能性があります。ただし、ダッカの都市環境・規則で作られたラベルであり、日本の歩道の実態や法令違反を示すとは限りません。地域の歩道について結論を出すには、現地の観察や自治体の情報を別に集めます。

## 公開を保留している理由

YouTube由来フレームの出典動画・個別ライセンス・帰属条件、人物や車両番号などのプライバシー、ラベルの一貫性、ファイルとSHA-256は未確認です。ファイル合計は約4.31GBで、無料Colabや学校の回線で扱いやすい規模かも検討が必要です。

1. Version 1のファイル一覧・サイズ・固定URL・SHA-256を記録する。
