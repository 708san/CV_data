# FootpathVision

## 概要

- 出典：[Mendeley Data v1](https://data.mendeley.com/datasets/szkhrh8dc8/1)（DOI: 10.17632/szkhrh8dc8.1）
- 説明上の規模：ダッカの歩道画像1,238枚。ZIP 2件、計約4.31 GB
- ラベル等：歩道の通行を妨げる物がある画像／ない画像
- 画像の由来：著者撮影と、Creative Commonsライセンスと説明されたYouTube動画から抽出したフレーム
- ライセンス表示：CC BY 4.0
- 状態：保留。画像は未取得、再配布審査と実体検査は未実施。

## 高校生の課題とのつながり

通学路や近所で歩道を通りやすくするには何が必要か、歩道の状態を比較する課題にできます。ただし画像はダッカの特定環境を写しており、日本の歩道へそのまま当てはめられません。モデルの予測で安全な経路を決めたり、通行可否を判断したりしません。

## 公開前に確認すること

- YouTube動画ごとの元URL、ライセンス、動画投稿者の再配布条件
- 通行人・車両・看板等のプライバシーと第三者権利
- 固定版1のファイル一覧、SHA-256、画像とラベルの対応、重複・破損
- 約4.31 GBから授業用に扱える部分集合を用意できるか。部分集合の固定・再配布条件

権利と大容量の扱いが明確になるまで、取得と公開を保留します。
