# Fruits-360 100×100（固定版なし・取得保留）

## 公式情報

公式の[`fruits-360-100x100`リポジトリ](https://github.com/fruits-360/fruits-360-100x100)はCC BY-SA 4.0を掲示しています。READMEの版は2026.10.27.0で、200,201枚・278クラス・100×100と説明します。果物だけでなく野菜・ナッツ・種子・きのこを含み、回転させた同じ個体の画像もあります。白い背景に回転する被写体を撮影し、背景を白く置き換える処理を行ったと説明されています。

## 保留理由

2026-11-08に確認したGitHubの[Releases一覧](https://github.com/fruits-360/fruits-360-100x100/releases)にはReleaseがありません。更新されるブランチのスナップショットは固定タグ付きRelease assetではなく、取得元を当ライブラリの固定版条件へ登録できません。未固定のZIPを取得・展開したり、再配布したりしません。

CC BY-SA 4.0の掲示自体は確認済みですが、共有する変換版を同ライセンスで提供する条件の整理も必要です。取得を開始していないため、件数・ラベルの実態、重複、学習・評価への撮影系列の漏れは未検査です。

## 教材としての見込み

固定背景の画像分類を試し、回転系列が学習用と評価用にまたがると評価が甘くなりうること、野菜や品種を別クラスにしたときの分類範囲を考える課題に向きます。正式候補へ戻す条件は、固定タグReleaseと既知SHA-256を備えたデータ取得先です。
