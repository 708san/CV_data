# FruitSeg30（公開保留）

果物画像と前景マスクを使い、画像のどの部分が果物かを領域分割する候補です。公式ページでは30クラス、1,969画像と対応マスク、CC BY 4.0、512×512画像と説明されています。

## 現時点で確認したこと

- 公式公開APIのフォルダ構造を確認しました。
- 30クラスごとに`Images`と`Mask`が分かれる構造でした。
- Avocadoクラスでは画像72件・マスク72件があり、ファイル名は`10.jpg`と`10_mask.png`の対応でした。
- 代表の画像とマスク1組は、API記載のSHA-256と一致しました。
- 代表画像は512×512のJPEG RGB、マスクは512×512のPNGグレースケールとしてデコードできました。

## 公開保留の理由

1クラスの確認だけでは、全30クラスの画像・マスク対応、重複、マスク値の意味、元画像の権利、固定artifactのSHA-256を確定できません。全量検査と再配布条件の確認が終わるまで、`cvlesson`正式APIやartifact Releaseには追加しません。
