# FabricSpotDefect：衣類の染み位置を見つける候補

**状態：候補調査中。生徒向けライブラリからは取得できません。**

家庭で撮影した布の染みを、画像のどこに写っているか検出するデータです。衣類を洗濯する前に染みの位置を見つける道具や、衣類を補修・再利用する活動の題材になりそうです。染みの種類や落ちやすさを判定するデータではありません。

## 確認できた内容

- Mendeley Data v1、DOI: [10.17632/6574nhzm8x.1](https://data.mendeley.com/datasets/6574nhzm8x/1)
- データページのライセンス表示はCC BY 4.0です。
- ページの公開ファイル一覧は7,921ファイル、計944,595,824 bytesです。JPG 5,614点、YOLO形式のTXT 2,300点、COCO JSON 6点、YAML 1点を確認しました。
- COCO JSON 6点は公式ファイルIDとSHA-256を照合して解析しました。元画像用とみられる3点は1,014画像・3,288注釈で、拡張画像用とみられる3点は2,300画像・7,641注釈でした。
- 元画像1点を公式配布元から取得し、SHA-256とJPEGデコードを確認しました。人の写り込みがない布の接写でした。
- 論文は、画像を日常使用の衣類から収集し、人・動物実験を行っていないと説明しています。[論文](https://pmc.ncbi.nlm.nih.gov/articles/PMC11648198/)

## 公開前に残る確認

ページの説明と注釈ファイルの数に差があります。元画像の注釈数はページで3,286、確認したCOCOでは3,288でした。拡張画像の件数はページとCOCOで7,641ですが、論文本文のCOCO件数7,635とは異なります。また、ページは全画像を416×416と説明しますが、元画像用COCOには異なる寸法が記録されています。

元画像だけでも公開メタデータから見積もった合計は約742 MBです。COCO注釈の機械検査では、元画像と推定した1,014枚の注釈3,288件中29件が画像境界外でした。拡張画像側でも7,641件中63件が境界外でした。配布範囲のファイル一覧、画像と注釈の対応、元画像の権利・プライバシーを全量確認し、整形済みデータの固定Releaseを用意するまではライブラリへ登録しません。

授業で扱う場合も、モデルの出力は染み位置の目安に限ります。洗濯方法や衛生状態、衣類の品質を判断する用途には使いません。日本の衣類や家庭を代表するデータでもありません。
