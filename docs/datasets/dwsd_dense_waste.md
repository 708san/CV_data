# DWSD: Dense Waste Segmentation Dataset（地域ごみ課題の候補・品質保留）

## 一次情報と権利

- [Mendeley Data Version 1](https://data.mendeley.com/datasets/gr99ny6b8p/1)、DOI: `10.17632/gr99ny6b8p.1)
- 著者：Asfak Ali、Suvojit Acharjee、Md Manarul Sk、Salman Z Alharthi、Sheli Sinha Chaudhuri、Adnan Akhunzada
- MendeleyページはCC BY 4.0を表示。対応するData in Brief論文もCC BY 4.0で公開されています。
- 論文では、西ベンガル州の街路、公園、芝地、大学周辺などで著者らが携帯電話を使って撮影し、1,000枚以上から選んだ784枚を手作業で注釈したと説明しています。SNS由来画像ではなく、人対象研究を含まないとの倫理記載があります。
- ただし、画像全体の個別権利・プライバシー審査は未完了です。以下の初回技術監査では、注釈の欠落懸念も見つかりました。

## データ内容

論文と公式ページの説明は、784枚、2,350領域、14種類のごみカテゴリ、色付きセグメンテーションマスクを示しています。分割はtrain 640枚、test 144枚です。公開説明には、プラスチック容器・ボトル、金属ボトル、紙・カップ、ガラス、布、ナイロンなどが含まれます。

## 高校生の課題との接続

通学路や公園のごみ拾い・分別を題材に、画像内のごみの場所や種類を示す試作品を作る用途に接続できます。地域の清掃活動で、生徒が撮影した画像との違いを比べる課題にもできます。

データに撮影場所の座標や時系列はありません。西ベンガル州の画像から日本のごみ分布・量・清掃優先度を推定することはできず、地域の分別ルールや危険物の扱いも判定できません。清掃の判断は現地の人と自治体の案内で行います。

## 初回監査で見つかった問題

固定v1の公式API掲載値（252,719,363 bytes、SHA-256 `fb9229c330ed253f4fb7c18bd46dddebe4df6f8d3f602747f505ff7601a11737`）とダウンロードZIPが一致しました。CRC検査に成功し、パストラバーサル、シンボリックリンク、重複ファイル名はありません。Train 640組・Test 144組の画像784枚とマスク784枚がIDで対応し、全1,568 PNGを448×448でデコードできました。画像の完全一致重複はありません。

一方、マスク81枚が全て同一の黒一色でした。対応画像81枚を一覧で確認したところ、ごみが見える画像が複数含まれていました。背景例として意図されたものか、注釈漏れかを全件で確かめられていないため、現状のマスクをそのまま教材ラベルとして使うことは保留します。画像とマスクをそのままReleaseへ追加しません。

## 採用前に必要な確認

1. Version 1の固定ファイル一覧・取得先・各ファイルのサイズとSHA-256を記録する。
2. SHA-256を照合してから安全に展開し、画像・マスクの対応、寸法、クラス値、破損、重複、分割漏洩を確認する。
3. 全画像を一覧で確認し、人物・番号・第三者権利など、公開できない画像がないかを確認する。
4. すべての確認を通過した場合のみ、CC BY 4.0の帰属と変換内容を添えた共通形式artifactを作り、Release/APIへの採用を再審査する。

現時点では課題との接続が見込める候補ですが、空マスクによる注釈欠落の懸念と個別権利・プライバシー審査が残るため、台帳でholdにしました。生徒向けカタログ・API・Releaseには追加しません。
