# BDFD9: Bangladesh Centric Fabric Defect Dataset

## 概要

- 出典：[Mendeley Data v1](https://data.mendeley.com/datasets/z49cc7zvfc/1)（DOI: 10.17632/z49cc7zvfc.1）
- 説明上の規模：1,088枚、ZIP 765 MB
- ラベル等：布の欠陥9クラス、YOLOv8形式の矩形ラベル
- 分割：train 775／validation 208／test 105。複数欠陥画像はクラス別フォルダに重複配置される
- ライセンス表示：CC BY 4.0
- 状態：候補。画像・ラベルは未取得、再配布審査と実体検査は未実施。

## 高校生の課題とのつながり

服の穴やほつれを見つけて修繕し、衣服を長く使うことを考える物体検出の題材になります。画像はバングラデシュの縫製工場で撮影された布地で、家庭の服や日本の衣料品へそのまま一般化できません。品質保証や商品の合否判定には使いません。

## 公開前に確認すること

- 固定版1のファイル一覧・SHA-256、ラベル形式と画像対応
- クラス別フォルダに複製された同一画像を考慮した分割・漏洩確認
- 従業員、製品のブランド表示など第三者の写り込み
- CC BY 4.0の表示条件、画像の権利、変換・再配布条件
- 765 MBの原本を安全に扱い、Colabで必要分だけ取得できるか

公開条件とファイル実体を確認するまで、取得APIには登録しません。
