# Indoor Plant Varieties（候補・実物未監査）

## 出典とデータ概要

[Indoor Plant Varieties for Computer Vision Applications, Mendeley Data v1](https://data.mendeley.com/datasets/ct79299k27/1)、DOI `10.17632/ct79299k27.1)。公式ページはCC BY 4.0を表示しています。投稿者はSajib Bin Mamun、Md Asraful Sharker Nirob、Md Taimur Ahad、Mashreka Akter、Pranta Saha、Md Assaduzzamanです。

投稿者の説明では、2023年にバングラデシュ農業開発公社と近隣苗圃で7種類の観葉植物を収集し、スマートフォンで撮影した元画像1,172枚を掲載しています。拡張版は7,000枚と記載され、農学者がクラス名を確認したと説明しています。

## 高校生向け課題案

家や学校の観葉植物を見分ける分類課題や、撮影場所・光・背景が変わると予測がどう変わるかを比べる題材になり得ます。まず元画像だけを使い、人工拡張画像を同じ分割に混ぜない構成を検討します。植物名の予測を毒性、食用、ペットや人の安全判断に使わないでください。
