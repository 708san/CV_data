# ConMetal-6 subset（候補・実物未監査）

## 出典と公開範囲

[ConMetal-6 subset, Mendeley Data v1](https://data.mendeley.com/datasets/ch34f38kz5/1)、DOI `10.17632/ch34f38kz5.1)。公式ページにはCC BY 4.0と表示されています。投稿者はDiyana Ranasinghe、Mehrdad Arashpourです。

公式説明によると、公開版は全体データのテスト分割に当たる232枚です。6種類の金属合金に4,620個の矩形注釈があり、YOLO形式で提供されます。画像はメルボルンでモバイルRGBセンサーを使って撮影し、ラベルは磁石テスト、scratch test、専門家確認で作成したと説明されています。全2,304枚のデータは研究目的で申請提供と記載されています。

## 高校生向け課題案

生徒が自分で用意した訓練画像で金属物体検出モデルを作り、この公開テスト分割で検出位置を評価する題材になり得ます。現時点で公開ページの説明から確認できるのはテスト分割のみなので、このデータだけでモデルを訓練する教材にはできません。合金名や検出結果を、実際の廃材処理・材質判定の根拠として使わないでください。
