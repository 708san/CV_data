# Fresh and Rotten Fruits

## 状態

整形artifact v0.1.0を準備し、取得APIへの登録案を作成しました。GitHub Release assetの公開が完了するまでは、`datasets.list_available()`には表示されず、取得もできません。

## 教材で使えること

果物8種類を「fresh／rotten」の画像ラベルに分ける分類課題です。食品ロスについて考えながら、画像の見た目とラベルの関係、クラスごとの誤分類を調べられます。高校生に身近な果物を題材にできます。

ラベルは研究データ内の見た目の分類です。食用可否、食品安全、健康状態を判定しません。モデルの出力で食べるかどうかを決めてはいけません。

## 出典と権利

公式の[Mendeley Data v1](https://data.mendeley.com/datasets/bdd69gyhv8/1)はCC BY 4.0を表示しています。著者の説明では、原画像は青果店や実地で集められ、新鮮・傷みのラベルは農業機関の専門家の助言を得て付けられています。出典・変更内容はartifactの`LICENSE.md`に記載しました。

## 整備内容

- 原画像3,200枚、16クラスを固定SHA-256照合後に検査しました。増強画像12,335枚は含めていません。
- 全3,200枚を画像デコーダで読み込み、7枚の完全一致重複を除外しました。成果物は3,193枚です。
- 画素を最大512pxに縮小し、JPEG品質86で再符号化しました。向きを補正し、元の画像メタデータを除いています。
- クラスごとにseed 42でtrain／validation／testへ分割しました。
- 64枚（全16クラスから各4枚）の代表画像を目視し、人物・ロゴ・無関係な写り込みは見つかりませんでした。全画像の手作業レビューではありません。
- 固定artifact ZIPは150,919,158 bytes、SHA-256は`1ca92043fbb0ebbf86ddac5fec2c264e39151ab0d9def1b618002772d9b182eb`です。

内訳と完全一致重複の記録は[全量監査JSON](../../reports/fresh_rotten_fruits-v1-full-audit.json)を参照してください。
