# Recyclable Waste Image Dataset（共通artifact準備・公開保留）

## 出典と権利表示

[Mendeley Data v1](https://data.mendeley.com/datasets/h5pxbsdz4m/1)、DOI `10.17632/h5pxbsdz4m.1`。掲載ページはCC BY 4.0を表示し、公開1,000枚は著者自身が施設・市街・家庭で集めた画像で、第三者データセット由来の画像は公開分から除外したと説明します。これは掲載者の説明を確認したもので、全画像の第三者権利・肖像・商標の独立確認を意味しません。

## 全量技術監査

- 固定v1の公開APIにある989画像（1,707,541,468 bytes）を全件取得し、保存済みファイル一覧のサイズ・SHA-256と照合しました。ファイル集合digestは`154381f20cb1775f24e39801a3516cc0607d8330502924b9da6c7f2cbcfd8339`です。掲載件数1,000枚との差11枚は取得できず、補完していません。
- 989枚すべてJPEGとしてImageIOでデコード成功しました。
- クラス内の完全一致重複12ファイルを検出し、一意画像は977枚です。クラス内訳は段ボール537、ガラス49、金属95、紙98、プラスチック210。重複除去後は533、49、90、96、209です。
- 画像サイズは524×524から4,284×5,712まで幅があります。104枚にGPSを含むEXIF情報を検出しました。
- 代表5枚を目視し、製品やブランドの文字が見える画像がありました。この5枚では人物を確認しませんでしたが、全画像の人手によるプライバシー確認は未完了です。

## 共通artifact v0.1.0

一意画像977枚を標準化し、各クラス内でseed 42によるtrain/val/test分割を加えました（683 / 146 / 148枚）。画像はEXIF方向を適用して長辺512px以下へ縮小し、JPEG quality 86で再符号化しています。GPS・EXIF等の元画像メタデータは出力へ残さず、完全一致重複12枚を除外しました。画素変換と分割は再現可能な変換スクリプトに記録し、元画像は変更していません。

ZIPは93,671,127 bytes、SHA-256 `99e80d8c0a083b65f7c5550afc87ec2db985b612762d55475a425b8f6db784ed`。982ファイル（977画像と説明・ラベル類）を収録し、ZIP破損・危険パスは検出されませんでした。Gitにはデータ本体を収録せず、Releaseも作成していません。

## 高校生向けの課題

「画像からごみ素材を分類できるか」を試し、撮影環境・床や背景・ブランド文字が結果へ与える影響を比較できます。クラス数には大きな偏りがあるため、正解率だけで比較せず、クラス別再現率やMacro F1を見ます。地域ごとに分別ルールが異なるので、このモデルで現実の分別を自動決定しません。

## 公開状態

MendeleyのCC BY 4.0表示と、公開分が著者自身の収集画像だという説明を確認しました。公開前に全画像のプライバシー・権利レビューを完了し、画像中のブランドや個人情報の扱いを確定する必要があります。そのため候補とartifactは準備済みですが、正式API・課題一覧・データReleaseは保留しています。
