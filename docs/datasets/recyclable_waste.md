# Recyclable Waste Image Dataset（リサイクル素材の画像分類）

## 出典と権利表示

[Mendeley Data v1](https://data.mendeley.com/datasets/h5pxbsdz4m/1)、DOI `10.17632/h5pxbsdz4m.1`。掲載ページはCC BY 4.0を表示し、公開1,000枚は著者自身が施設・市街・家庭で集めた画像で、第三者データセット由来の画像は公開分から除外したと説明します。これは掲載者の説明を確認したもので、全画像の第三者権利・肖像・商標の独立確認を意味しません。

## 全量技術監査

- 固定v1の公開APIにある989画像（1,707,541,468 bytes）を全件取得し、保存済みファイル一覧のサイズ・SHA-256と照合しました。ファイル集合digestは`154381f20cb1775f24e39801a3516cc0607d8330502924b9da6c7f2cbcfd8339`です。掲載件数1,000枚との差11枚は取得できず、補完していません。
- 989枚すべてJPEGとしてImageIOでデコード成功しました。
- クラス内の完全一致重複12ファイルを検出し、一意画像は976枚です。クラス内訳は段ボール537、ガラス49、金属95、紙98、プラスチック210。重複除去後は533、49、90、96、209です。
- 画像サイズは524×524から4,284×5,712まで幅があります。104枚にGPSを含むEXIF情報を検出しました。
- 整形済みの一意画像977枚すべてを縮小一覧で目視しました。内容は概ね各素材ラベルと一致し、明らかな無関係画像やクラス違いは見当たりませんでした。
- 縮小一覧では、明瞭な人物の写り込みは確認されませんでした。包装上の肖像写真らしきものが1件あり、商品名・ブランド文字は複数画像に見えます。これは全画像の法的な肖像・商標審査ではありません。
- 全件目視の方法と範囲：[Recyclable Waste visual review](https://github.com/708san/CV_data_artifacts/blob/main/reports/recyclable-waste-visual-review-2026-11-08.json)。

## 共通artifact v0.1.0

一意画像977枚を標準化し、各クラス内でseed 42によるtrain/val/test分割を加えました（683 / 146 / 147枚）。画像はEXIF方向を適用して長辺512px以下へ縮小し、JPEG quality 86で再符号化しています。GPS・EXIF等の元画像メタデータは出力へ残さず、完全一致重複12枚を除外しました。画素変換と分割は再現可能な変換スクリプトに記録し、元画像は変更していません。

ZIPは93,564,328 bytes、SHA-256 `71d71622b65c44d2748e296ff23e8ed49c2f3e4e788301f1d9128d34e0affd1f`。982ファイル（976画像と説明・ラベル類）を収録し、ZIPのCRCと全981ファイルのmanifest照合に成功しました。データ本体はGitに含めず、固定Release assetとして公開しています。

## 高校生向けの課題

「画像からごみ素材を分類できるか」を試し、撮影環境・床や背景・ブランド文字が結果へ与える影響を比較できます。クラス数には大きな偏りがあるため、正解率だけで比較せず、クラス別再現率やMacro F1を見ます。地域ごとに分別ルールが異なるので、このモデルで現実の分別を自動決定しません。

## 公開状態

MendeleyのCC BY 4.0表示と、公開分が著者自身の収集画像だという説明を確認しました。全977枚の縮小一覧による内容・写り込み確認は完了しましたが、第三者の画像権利、肖像、商品表示の扱いを含む再配布審査は未完了です。整形済みの固定Release assetは公開されていますが、権利審査が終わるまで`cvlesson`の取得APIと生徒向け一覧からは非公開です。

## 2026-11-09 権利・成果物再確認

Mendeley v1はCC BY 4.0を表示し、公開分は投稿者自身が収集した画像と説明しています。帰属表示・変更内容の明記を条件に、表示されたライセンス範囲で再配布可能と判断しました。全977枚の目視では分類内容に大きな不一致や明瞭な通行人は見当たりませんでした。一部に商品ブランド・包装文字と、包装上に印刷された肖像らしき画像があります。データのラベルは素材カテゴリであり、ブランド名や人物の識別ラベルは含みません。商標・肖像などの権利はCC BYとは別に扱います。

ZIPを再照合し、982ファイルすべてのmanifestサイズ・SHA-256一致、CRC成功を確認しました。公開版v0.1.1では政治キャンペーンポスターと人物肖像が写った紙画像1枚を除外しました。
