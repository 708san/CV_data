# Recyclable Waste Image Dataset（課題適合・第三者権利は公開保留）

## 高校生の身近な課題

学校や地域のごみ回収場所で、「紙・段ボール・プラスチック・金属・ガラスの素材を画像から分けられるか」を試し、背景や明るさを変えたときの誤分類を調べられます。結果をもとに分別掲示や回収場所の配置を見直す企画に発展できます。

このデータのラベルは素材の種類です。日本の自治体ごとの分別規則を表すものではなく、モデルだけで実際の廃棄判断を決める用途には使いません。課題では、地域のルールを別に調べ、人が判断する分別方法と混同しないようにします。

## 出典とライセンス

[Mendeley Data v1](https://data.mendeley.com/datasets/h5pxbsdz4m/1)、DOI `10.17632/h5pxbsdz4m.1)。掲載ページはCC BY 4.0を表示し、公開画像は投稿者自身が施設・市街・家庭で集め、第三者データセット由来画像を公開分から除いたと説明しています。表示されたライセンス条件として、帰属表示と変更内容の明記が必要です。

これは個別の第三者画像・肖像・商標等の権利がすべて確認されたという意味ではありません。包装上の印刷肖像らしきもの1件と、複数画像の商品名・ブランド文字が見つかっています。権利・プライバシーの確認を終えるまで、再配布Releaseと正式APIを保留します。

## 全量技術監査

- 公式公開APIの989画像（1,707,541,468 bytes）をすべて取得し、ファイル一覧のサイズ・SHA-256と照合しました。ページ記載1,000枚との差11枚は補完していません。
- 989枚すべてJPEGとしてデコード成功。完全一致重複12枚を除き、一意画像は977枚です。
- 一意画像のクラス内訳は段ボール533、ガラス49、金属90、紙96、プラスチック209です。重複除去前は537、49、95、98、210です。
- 元画像104枚にGPSを含むEXIF情報があり、準備済みartifactからEXIF/GPS等を除去しました。
- 一意画像977枚を縮小接触シートですべて確認しました。内容は概ね素材ラベルと一致し、明瞭な通行人は見当たりませんでした。印刷肖像らしきものとブランド表示は別途権利確認が必要です。

## 共通artifact v0.1.0

重複を除いた977枚を、EXIF方向を適用して長辺512px以下・JPEG quality 86で標準化し、seed 42でクラス内分割しました（train 683 / val 146 / test 148）。画像・ラベル等982ファイルのZIP CRCとmanifest内のサイズ・SHA-256を確認しました。ZIPは93,671,127 bytes、SHA-256 `39c52710ddaeb4e662dbbf3ba7cd95725a8b11cf2b22434d04bc52626b721299`です。バイナリはGitやPyPIに含めず、GitHub Releaseも作成していません。

## 判断の範囲

CC BY 4.0の表示と帰属・変更表示条件は確認済みです。学校の分別回収を題材にできるため教育上の適合性もあります。一方、第三者の商品表示・印刷肖像等を含む再配布・プライバシー確認は未完了です。よって、現段階は「授業課題としては有用、正式公開は保留」です。全画像の縮小目視方法と限界は[visual review report](https://github.com/708san/CV_data_artifacts/blob/main/reports/recyclable-waste-visual-review-2026-11-08.json)に記録しています。
