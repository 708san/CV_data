# Recyclable Waste Image Dataset（保留中）

リサイクル分別を画像分類の課題に結び付けやすい候補です。公式Mendeleyページでは、著者が施設・市街・家庭で撮影した画像を含み、CC BY 4.0と説明されています。

## 現在の状態

まだ`cvlesson.datasets`の正式APIや`CV_data_artifacts`のReleaseには追加していません。

公式公開APIのファイル一覧を確認したところ、READMEを除く画像ファイルは989枚で、ページに記載された1,000枚と一致しませんでした。合計サイズも約1.7GBあり、固定アーカイブのSHA-256が登録されていません。そのため、画像を取得・ミラー・整形・生徒向け公開する前に、件数と配布構造を再確認します。

追加で、公開APIの9フォルダから代表画像を1枚ずつ取得して実体を確認しました。9枚すべてでAPI記載のSHA-256と一致し、JPEGとしてデコードできました。画像サイズは524×524から4,284×5,712までばらつき、iPhoneのEXIF情報を含む画像もありました。これはサンプル検査であり、989枚全量の破損・重複・個人情報・権利の検査ではありません。

## 想定する課題

- ごみを5種類に分類できるか
- 撮影場所が変わると誤分類は増えるか
- 「画像分類の結果を分別の補助に使う」と「実際の分別を自動決定する」を区別できるか

このモデルは実際の廃棄物処理や安全判断の自動決定には使いません。クラスの地域差、撮影条件、背景の影響を記録する教材用の実験として扱います。
