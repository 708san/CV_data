# Image Dataset of Indian Coins（公開保留）

インド硬貨の画像から額面を分類する課題候補です。表裏や記念デザインによる違い、同じ額面でも見た目が変わる影響を調べる教材に向きます。画像分類の結果を通貨の真正性や金融判断には使いません。

## 現時点で確認したこと

- 公式Mendeley Dataの固定版1とCC BY 4.0表記を確認しました。
- 固定ZIPは728,966,897 bytes、SHA-256は`93405d0883907d2775b58fe7b8c18ee6d4a34d540b090aa687f20c74d731500d`です。
- ZIPの中央ディレクトリは6,846項目で、6,680枚のJPEGと166個のフォルダでした。パス逸脱・シンボリックリンク・非画像ファイルはありません。
- 額面フォルダは7種あり、ZIP内件数は1 Rs 779枚、2 Rs 2,042枚、5 Rs 1,918枚、10 Rs 841枚、20 Rs 324枚、25 Paisa 241枚、50 Paisa 535枚です。合計は公式ページ記載の6,680枚と一致します。
- 各額面から1枚、計7枚を固定ZIPの範囲取得で確認し、ZIP CRCとJPEGデコードに成功しました。画像サイズは575×768または768×768 RGBでした。
- フォルダには額面・コインの記念デザイン・表裏が含まれます。学習と評価を分ける際は、同じ記念デザインや表裏をまたいだ分割を避ける必要があります。重複・同一コイン系列の全量検査は未完了です。
- 固定source manifestを`CV_data_artifacts`に記録しました。元画像権利、全量画像デコード・重複、グループ分割設計が終わるまで、共通artifactと正式教材への追加は保留します。
