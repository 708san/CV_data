# LeFood-Set: Leftovers Food Dataset（有望候補・公開保留）

- **公式版**：[Mendeley Data Version 1](https://data.mendeley.com/datasets/cchsk79jkt/1)（DOI: 10.17632/cchsk79jkt.1）
- **作者**：Yuita Arum Sari、Yudi Arimba Wani、Atsushi Nakazawa
- **表示ライセンス**：CC BY 4.0（Version 1のページ表示。個別ファイルと再配布条件は未確認）
- **状態**：公式説明の机上確認のみ。画像・ファイルは取得していません。

## データの内容

公式ページは、インドネシア料理の食前・食後画像524組と、対応する表計算ファイル `data_original.xlsx` の説明を掲載しています。各組には食カテゴリ、食前画像名と重量、食後画像名と重量、観察者が評価した7段階の残量レベルが含まれるとされています。重量はデジタル秤で測定した値と説明されています。

この対応関係がファイル実体でも保たれているか、画像と表の行が欠けずに対応するかは未確認です。

## 高校生の課題との接続

家庭の食事や学校・食堂の食べ残しを減らしたい場合に、画像からの残量推定を実際の重量と比べ、目視や画像だけで分かること・分からないことを調べる教材候補です。家庭や食堂で改善を考えるなら、実際の献立や提供量、曜日なども記録して、画像による推定を秤の計測と照らし合わせます。

データはインドネシア料理を対象としているため、日本の献立、食器、盛り付け、撮影位置へそのまま一般化できません。画像だけで食べ残し重量を確定したり、学校の食品ロス量を推計したりする用途には使いません。

## 公開を保留している理由

MendeleyのページにはCC BY 4.0が表示されていますが、ファイル一覧、アーカイブサイズ、固定SHA-256、実際の画像・表、画像と計量値の対応、第三者権利・プライバシーをまだ確認していません。引用・帰属の必要事項、画像を含む再配布条件もファイル実体と照合する必要があります。
