# LeFood-Set: Leftovers Food Dataset

## 概要

- 出典： [Mendeley Data v1](https://data.mendeley.com/datasets/cchsk79jkt/1)（DOI: 10.17632/cchsk79jkt.1）
- 説明上の規模：インドネシア料理の食前・食後画像524組
- ラベル等：料理名、食前・食後の重量、観察者による食べ残し7段階評価
- ライセンス表示：CC BY 4.0
- 状態：候補。画像・対応表は未取得、再配布審査と実体検査は未実施。

## 高校生の課題とのつながり

家庭や食堂で食べ残しを減らす工夫を考え、食事前後の見た目と重量・評価の関係を調べる題材にできます。撮影された料理・盛り付け・食文化は限られているため、見た目から重量を推定する結果を他の料理や地域へ一般化しません。モデルを食事量や健康状態の判断に使いません。
