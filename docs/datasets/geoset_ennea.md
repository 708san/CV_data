# GeoSetEnnea（公開保留）

文具などの物体を画像の中から見つけ、位置と種類を示す物体検出の候補です。公式ページでは、9種類・966画像・8,253個の位置注釈、CC BY 4.0と説明されています。

## 現時点で確認したこと

- 公式Mendeley公開APIのフォルダ別メタデータを確認しました。
- 分割済みの画像は train 676件、valid 193件、test 97件で、合計966件でした。
- 対応するYOLO形式のラベルは train 676件、valid 193件、test 97件でした。
- それとは別に、augmented 810件と raw 154件のフォルダがありました。
- 各ファイルのメタデータにはSHA-256がありますが、公開用の単一固定アーカイブSHA-256ではありません。
- train/valid/testから画像3枚と対応するYOLOラベル3枚を取得し、6ファイルすべてでAPI記載のSHA-256と一致しました。画像は640×640 JPEGとしてデコードでき、ラベルは5列のYOLO形式で座標範囲も確認できました。

## 公開保留の理由

CC BY 4.0の表記だけでは、教材用にどのフォルダを採用し、どの変換を加えて再配布するかは決まりません。画像本体とラベルの対応、重複や拡張画像の扱い、元画像の権利、固定取得方法を全量監査してから、artifactリポジトリへの登録を判断します。

そのため、現在の`cvlesson`正式APIや生徒向けNotebookには追加していません。検出課題を先に公開する場合も、検査済みの固定artifactとmanifestを用意し、分類データと混同しない別アダプターにします。
