# GeoSetEnnea（共通artifact準備済み・公開保留）

幾何用具9種類を画像から見つけ、位置と種類を予測する物体検出データです。授業前後に共有のコンパス・定規・分度器を確認し、返却や補充が必要な道具を整理する試作に使えます。商品を並べた画像や文具店・図書館の写真が中心なので、日本の教室の道具をそのまま認識できるとは限りません。現場導入ではなく、課題の試作・検証用です。

## 実体監査（2026-11-10）

- Mendeley Data v1の画像966件とYOLOラベル966件について、公開APIに記載されたSHA-256を全件照合しました。
- 画像966件はすべて640×640 JPEGとしてデコードできました。
- 8,253個の注釈を提供者のMetadata.csvと全件照合し、クラス・座標の不一致はありませんでした。
- 画像とラベルを照合したうえで、元データの199撮影系列をファイル名からまとめました。元のtrain/valid/testでは81系列が複数の分割にまたがっていました。準備版では系列を分けず、train 676 / valid 193 / test 97を維持して分け直しました。
- 全画像の一覧を目視し、道具の種類・枠のおおまかな一致を確認しました。商品パッケージ、ブランド表記が見える画像があります。個別の商標・画像権利については結論を出していません。
- JPEGにGPSやEXIFなどの撮影メタデータは見つかりませんでした。共通検証器でartifactを検証済みです。ZIPは55,650,689 bytes（LICENSE.mdを含む1,938ファイル）、SHA-256は`84d8b42f88eb5c6582657b33014689d7d8342a261302486c517558609ec9033b`です。

## 公開を保留している理由

公式Mendeley Data v1はCC BY 4.0と表示しています。掲載説明では著者がバングラデシュ・ダッカの文具店や図書館で撮影し、9種類・966画像・8,253注釈を収録したとされています。CC BY 4.0の表示と、写真に含まれる第三者の商品・ロゴ等の権利は分けて扱います。再配布時の帰属表示、画像内の第三者要素、公開利用条件の確認が終わるまで、Release・正式APIには追加しません。

## 共通形式化で行った変更

元の640×640画像とYOLOラベルはそのまま保持しています。共通の`annotations.jsonl`と`metadata.jsonl`を追加し、撮影系列をまとめて分割し直しました。元のカメラ機種を含むMetadata.csvと、別保管のraw/augmentedフォルダはartifactに含めていません。画像・ラベルをGitやPyPIには含めません。
