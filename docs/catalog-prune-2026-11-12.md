# 生徒向けカタログの見直し（2026-11-12）

ユーザー承認により、次の7件を生徒向け一覧・取得APIから除外しました。配布元のライセンス記録、監査資料、既存の固定Release assetは削除していません。

| ID | 除外理由 |
|---|---|
| `fashion_mnist` | ベンチマーク分類の練習を超える、身近な課題と次の行動を定められない |
| `bdroadsigns` | バングラデシュの標識で、日本の交通ルールや地域の課題に直接適用できない |
| `smallfishbd` | 対象魚種・地域が限定され、生徒が取り組む課題との接点が明確でない |
| `pistachio_image_dataset` | 2品種の見分けが、生徒の日常の困りごとに結び付かない |
| `chakmalipi` | 文字デジタル化を求める利用者・具体的作業が現時点で定まっていない |
| `food_waste_bangladesh` | ラベルが撮影場面で、廃棄物の量や削減の行動につながらない |
| `pust_cafeteria_food` | 料理を検出した後に解決する困りごとが明確でない |

除外後、生徒向けAPIは19件です。次に、権利と用途を先に確認した新規データを3件追加し、データ選定を完了する方針です。
