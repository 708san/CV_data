# 画像AI、どれを使う？

更新日：2026-11-14。高校生が、使える画像データや画像AIの方法を選ぶための案内です。生徒向けに登録されているデータは**23種類**あります。ここに載せた件数は登録時の数です。

## まず、やりたいことを選ぼう

| やりたいこと | AIがすること | 使えるデータ |
|---|---|---|
| 写真を種類ごとに分けたい | 写真を見て、あらかじめ決めた種類を予想します。例：ごみの素材、果物の状態 | [種類を予想するデータ](#写真を種類ごとに分ける) |
| 写真から重さなどの数を予想したい | 写真1枚、または撮影前後の写真から数値を予想します | [数値を予想するデータ](#写真から数値を予想する) |
| 写真に書かれた文字を読みたい | 文字と、その場所を読み取ります | [文字を読むデータ](#写真の文字を読む) |
| 写真の中の物を見つけたい | 物の名前と場所を四角い枠で示します | [物の場所を見つけるデータ](#写真の中の物を見つける) |
| 写真の一部を塗り分けたい | 指定した物の形に沿ってマスク（色のついた範囲）を作ります | [写真の一部を塗り分けるデータ](#写真の一部を塗り分ける) |
| 新しい絵を作ったり、写真の雰囲気を変えたい | 文章や元画像から画像を作ります | [画像を作る・変える方法](#画像を作る変える) |

「ラベル」は写真につけた正解の種類や答えのことです。「学習」は、答え付きの写真を見せてモデルに予想のしかたを覚えさせることです。

## 画像を作る・変える

画像生成では文章から絵を作ったり、元の写真を別の雰囲気に変えたりできます。データセットの写真を使わず、自分で考えた文章や画像を入力する方法もあります。登録済みLoRA（絵柄を追加する小さなモデル）は[4種類](image-generation.md#登録済みlora)あります。画像生成は数GBのモデル取得とGPUメモリが必要になることがあります。

## ライセンスを読むとき

表のライセンスは、登録時にデータに表示されていた条件です。

- **CC BY**：作者や出典を表示する条件があります。変更したら変更したことも示します。
- **CC BY-NC**：出典表示に加えて、商用利用はできません。
- **CC0**：著作権について広く自由な利用を認める表示です。出典を記録しておきましょう。
- **MIT License**：著作権表示とライセンス文を残す条件があります。

* `sky_weather_next_day`には、データのライセンスとは別に、気象情報サービスの利用条件もあります。出典表示や利用方法を決めるときは、先生に確認してください。どのデータも、第三者の権利や個人情報など別の条件が関係する場合があります。公開・配布する前に先生と確認しましょう。

## Colabでデータを見てみる

データIDは、プログラムで使う名前です。次の例ではトマトの葉データを取得し、表と写真を見ます。初めて取得すると、データがダウンロードされます。

```python
from cvlesson import datasets

data = datasets.get("tomato_leaves")
print(data.to_df().head())  # 写真の場所やラベルを表で見る
_ = data.show_examples(6)  # 写真を6枚見る
```

写真の場所や表の列はデータごとに違います。別のデータを使うときは、上の表からIDを選び、`"tomato_leaves"`の部分を置き換えてください。最初は表や写真を見て、どんな情報が入っているか確かめましょう。
